# SecureUSB Guardian (Endpoint USB Malware & Integrity Scanner)

> **Tech Stack:** Python 3 (`os`, `hashlib`, `datetime`) | **Focus:** Endpoint Security, Static File Analysis & Cryptographic Auditing

## 1. Project Overview
**SecureUSB Guardian** is a modular, Python-based endpoint security tool designed to audit removable USB drives for suspicious files before execution. It combines recursive directory traversal, high-risk extension filtering, SHA-256 cryptographic hashing, and persistent audit logging to provide a lightweight malware-prevention layer for enterprise and retail workstations.

---

## 2. Purpose & Problem Statement
Removable USB devices remain a high-risk attack vector for malware injection, auto-run exploits, and unauthorized script execution on point-of-sale and corporate endpoints. **SecureUSB Guardian** introduces a pre-execution scanning mechanism, ensuring files are inspected and fingerprinted before being trusted or transferred into internal systems.

---

## 3. Key Features
* **Recursive Directory Traversal:** Inspects all nested files and subdirectories across a target removable drive.
* **Extension-Based Threat Filtering:** Flags executable and script file types commonly abused in malware delivery (`.exe`, `.bat`, `.vbs`, `.ps1`, `.scr`, `.cmd`).
* **SHA-256 Cryptographic Hashing:** Generates unique SHA-256 file fingerprints for integrity verification and threat intelligence lookup (e.g., VirusTotal).
* **Persistent Audit Logging:** Records every suspicious detection, timestamp, and file hash into `scan_log.txt` for incident response and compliance audits.
* **Standardized CLI Reporting:** Outputs structured `[INFO]` and `[WARNING]` status alerts for clear operational visibility.

---

## 4. Technologies & Libraries Used
* **Python 3** — Core programming language
* **`os`** — Filesystem traversal and extension/path parsing
* **`hashlib`** — SHA-256 cryptographic hash generation

## 6. How to Run the Application

1. **Verify Python Installation**
   ```bash
   python --version
   ```

2. **Clone and Navigate to Project Directory**
   ```bash
   git clone https://github.com
   cd "SecureUSB-Guardian-/Cybersecurity Projects"
   ```

3. **Run the Scanner**
   ```bash
   python main.py
   ```

4. **Provide Target USB Drive Path**
   ```text
   Enter USB path: D:\
   ```
